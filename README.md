# dino releases

Downloads for [dino](https://meetdino.com), the agent terminal: the macOS app (DMG) and the `dino` command line tool. Only binaries live here; see the Releases page.

- Homebrew: `brew install --cask asdf9384/tap/dino`
- Command line tool: `curl -fsSL https://meetdino.com/install.sh | sh`
